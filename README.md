## Overview

This repository collects Java implementations that explore object-oriented design, GUI applications, and reusable design patterns. It includes a larger circus-style game alongside focused applications and experiments.

## Contents

```text
.
├── Lab1 ... Lab9       # Java applications and design-pattern experiments
└── Final_Lab/          # Circus-style Java game
    └── src/final_lab/  # Game, level, shape, observer, iterator, and factory classes
```

The final project includes game entities such as clowns, plates, cups, and bombs, with classes implementing patterns including factory, observer, iterator, and state-oriented level handling.

## Running an Application

Projects were created with NetBeans. Open the desired folder as a NetBeans project, then run its configured main class.

For command-line work, compile from the relevant source directory. For example:

```bash
javac -d out src/final_lab/*.java
java -cp out final_lab.MainWindow
```

Some applications have external resources or IDE configuration files, so NetBeans is the most convenient way to open the complete project.
